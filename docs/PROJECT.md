# Project — Le Comptoir du Café

## Objectif

Créer un démonstrateur e-commerce premium, réaliste et réutilisable pour présenter les compétences de The Spark Studio sur des projets e-commerce locaux.

Le projet représente une maison de torréfaction familiale fictive fondée autour de 1896, avec cafés torréfiés sur place, matériel, sets, coffrets et ateliers.

## Positionnement visuel

Modern Heritage / Specialty Coffee / Editorial.

L'expérience doit évoquer une maison de torréfaction premium sans tomber dans un design générique de template e-commerce.

## Contenu métier

### Cafés

- origines
- assemblages
- éditions limitées
- café en grains ou moulu à la demande

### Machines & matériel

- machines espresso
- moulins
- méthodes douces
- accessoires

### Sets & coffrets

- Set Espresso
- Set Filtre
- Set French Press
- Set Découverte
- coffrets cadeaux

### Ateliers

Ateliers et dégustations gérés par Cal.com. Ils ne sont pas des produits PrestaShop.

## Principe de réutilisation

Le projet doit permettre de changer logo, identité, contenu, images, produits, catégories, coordonnées et fonctionnalités réellement variables sans réécrire l'architecture.
